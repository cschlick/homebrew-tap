# Cschlick Tap

## How do I install these formulae?

`brew install cschlick/tap/<formula>`

Or `brew tap cschlick/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cschlick/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
